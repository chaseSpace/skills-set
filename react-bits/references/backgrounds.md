# Backgrounds

Read this only for a full-bleed or section-level visual background. These are decorative companions to content, not substitutes for it. Begin with a lightweight CSS/canvas option; use WebGL, Three.js, OGL, or physics only when the page can afford the GPU and visual complexity.

## Choose by design direction

| Direction | Good starting components |
| --- | --- |
| Subtle product/marketing atmosphere | `Aurora`, `Beams`, `DarkVeil`, `Grainient`, `LightRays`, `Silk`, `Waves` |
| Technical or developer-tool visual | `DotGrid`, `FaultyTerminal`, `GridMotion`, `GridScan`, `Radar`, `Topography` |
| Energetic/colorful brand moment | `ColorBends`, `GradientBlinds`, `LiquidEther`, `Plasma`, `PrismaticBurst` |
| Spatial, immersive, or GPU-rich hero | `AeroShards`, `Ballpit`, `Galaxy`, `Hyperspeed`, `LiquidChrome`, `MoltenMetal` |
| Pixel/retro effect | `CRTWarp`, `Dither`, `LetterGlitch`, `PixelBlast`, `PixelSnow` |

Always create a foreground content layer with reliable contrast. Keep decorative layers behind it, do not capture clicks unless expressly interactive, and use a static or disabled fallback for reduced motion, touch-constrained, low-power, or off-screen conditions.
